# 잔여 오탐 보완 검증

이 문서는 0.5.3 이후의 보완 작업을 기록한다. **현재 중간 검증이며, 전체 파이프라인과 새 영상 검증은 아직 완료하지 않았다.**

## 확인한 원인과 수정

- 한 궤적이 실제 하강 정점을 건너뛰고 작은 밝은 조각에 연결되면 낙하 후보를 한 프레임 일찍 선택할 수 있었다. 두 후보가 실제로 관측된 접근 구간과 이후 구간을 공유하는지 확인하고, 크기와 하강 경로에 맞는 관측을 포함한 후보를 우선하도록 수정했다. 후보 좌표를 옮기거나 누락 관측을 생성하지 않는다.
- 정지 바닥 무늬를 움직이는 물체의 관측으로 연결하는 문제를 조사했다. 좌표와 프레임이 일치하는 실제 주변 픽셀 근거가 정지 배경을 명확히 가리키는 경우에만 이동 궤적의 근거에서 제외한다. 흐림, 불확실한 정합, 작은 물체, 오래된 근거는 중립으로 처리한다.
- 희미한 셔틀을 원본 해상도에서 복구하는 실험에서는 새로운 후보가 기존 탐색을 밀어내는 문제가 있었다. 실험 경로는 기존 관측과 탐색을 보존하도록 분리했으나, 최종 낙하 위치 개선이 아직 입증되지 않아 기본 기능으로 채택하지 않았다.
- 실제 라켓 반전, 옆 코트의 셔틀, 누락된 하강·반동 관측은 정지 배경 필터로 해결되지 않는다. 바닥과 비슷한 색의 벽도 있어 영상의 색상만으로 접촉을 확정할 수 없다.

## 현재 검증 범위

기존 24개 영상은 이번 작업의 개발·회귀 자료로 사용한다. 위치를 평가할 수 있는 13개와 가림·대상 불확실성으로 위치 점수를 매기지 않는 11개를 구분한다. 참조는 모델 결과를 보지 않고 작성한 AI 원본 영상 관찰 기록이며, 독립적인 사람의 정답 검수는 아니다.

동일한 기존 검출 결과와 실제 디코딩 픽셀을 사용한 추적·이벤트 단계 비교에서 기준 충족 영상은 **5/13 → 6/13**이었다. ordinary-12-a의 선택만 프레임150에서151로 바뀌었으며, 고정 참조점까지의 오차는6.61px에서4.25px로 줄었다. 허용오차6px와 참조는 변경하지 않았다. 기존 성공5개와 다른23개 영상의 선택 프레임·좌표는 유지됐다.

이는 후보 수 제한을 해제한 단계별 원인 검증이다. 새 검출기, 최종 원본 접촉 검사, 제품 기본 설정, 전체 영상 일반화 성능을 검증한 수치로 해석하면 안 된다. 6개 일치 중4개는 관측한 물체 중심,2개는 가린 구간의 추정 중심이다. 모든24개 결과는 계속 `REVIEW`이며 실제 최초 접촉이나 자동 IN/OUT을 확정하지 않는다.

추가8개 영상은 이번 보완 결과를 보기 전에 선정하고, 원본만 보고 작성한 참조를 봉인했다. 코드를 동결한 뒤 평가한다. 동일 프로젝트의 이번 회차 보류 자료이며, 프로젝트 역사 전체에서 처음 본 영상이나 외부 체육관의 독립 자료라고 주장하지 않는다.

## 채택 전 남은 확인

- 실제 픽셀 기반 정지 배경 검사 전후의 기존24개 결과와 처리 시간 비교.
- 원본 해상도 복구 후보의 전체 영상 추적 결과와 기존 성공 사례 보존 여부.
- 최종 채택 코드·설정 동결 후 전체 파이프라인, 원래 A1/B1 입력, 추가8개 영상 검증.
- 사용하지 않는 실험 코드와 검증되지 않은 기본 설정 제외, 패키지 무결성 확인.
