전체 테스트에 포함된 `test_media_verified_seek.py`의 9개 사례는 가변 프레임 간격, 회전, 편집 목록, 0이 아닌 시작 시각, 잘못된 디코더 시간값, 탐색 정보 누락·중복·개수 불일치 등을 다룹니다. 탐색 후 디코더 시간값이 목표 프레임과 맞지 않으면 순차 읽기로 돌아가며, 순차 읽기와 픽셀·시각이 같은지 검사합니다.

별도의 실제 개발 영상 측정은 각 입력에 한 번씩, 비교 대상을 별도 프로세스로 순서대로 실행했습니다. 환경은 CPU 4코어 제한, OpenCV 작업 스레드 1개, 디코더 스레드 2개였고 다른 작업이 함께 실행될 수 있었습니다. CPU 시간은 ffprobe 자식 프로세스를 포함합니다. [측정 요약](software-verification/native-seek-summary.json)에 원본과 구현 해시를 기록했습니다.

| 원본 읽기 구간 | 프레임 | 경과 시간, 이전 → 이후 | CPU 시간, 이전 → 이후 | 최대 메모리, 이전 → 이후 |
