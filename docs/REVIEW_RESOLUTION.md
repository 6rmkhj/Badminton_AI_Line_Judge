# 착지 판정 근거 연결과 원본 재확인 · 0.5.14

0.5.13에서는 원본 영상의 접촉 가능 영역 전체가 IN 또는 OUT으로 계산돼도 직접 접촉 확인용 진단이 REVIEW를 반복했습니다. 화면 대표 후보도 실제 영상 추정에 사용한 사건과 다를 수 있었습니다. 0.5.14는 실제 판정 경로와 근거를 연결하고, 추적에서 놓친 착지 정점을 원본으로 재확인합니다.

## 사용 시 달라지는 점

- 시점별 주 결과에 실제 사용할 수 있는 판정과 근거 종류를 표시합니다. 영상 추정은 **영상 추정 IN/OUT**으로 표시합니다.
- 첫 착지 가능 구간, 주 코트 경로 연결, 사건 통합, 경계와 위치 오차를 실제 원본 분석 결과로 설명합니다.
- 한 시점에서 유효한 판정이 나오면 최종 판정의 근거로 표시합니다. 다른 시점은 **독립 판정 없음·보조 영상**으로 구분합니다. 그 시점의 접촉이 확인됐다고 표시하지 않습니다.
- 미해결 결과는 실제 멈춘 단계와 다음 조치를 표시합니다. 분석 오류·모순된 판정·잘못된 입력 근거는 계속 확인할 수 있습니다. 직접 접촉 조건과 이전 비교 결과는 상세 영역에 보존합니다.
- 대표 후보·경로 사진·원본 근거를 실제 추정 사건에 맞춥니다. 선택한 사건이 후보 순위 7번째 이후여도 근거 사진에서 누락되지 않습니다.

새 ZIP을 새 폴더에 전부 압축 해제하고 `START.bat`를 실행하세요. A/B 영상을 올려 **기존 검수 근거 활용을 끈 새 분석**으로 시험합니다. 이전 결과를 다시 열면 표시를 갱신할 수 있지만 새로운 원본 탐색을 수행하는 것은 아닙니다.

## 원본 재확인 조건

기존에는 주 코트에 연결된 유일한 접근·반등 경로가 있어도 추적기가 정점 위치를 놓치면 원본 분석 전에 중단했습니다. 이제 `native_confirmation_required` 상태에서 원본 픽셀을 확인합니다. 경쟁 사건 없이 같은 주 코트에 연결되는 측정 경로가 하나여야 하며, 원본에서 정점과 앞뒤 3프레임씩 총 7프레임의 물체가 연속 관측돼야 합니다. 전후 운동·형상·시간 간격·위치 오차 검사도 통과해야 합니다. 가능한 접촉 영역과 오차 전체가 확인된 경계의 한쪽에 있을 때만 IN/OUT을 추정합니다.

원본에 남아 있지만 추적이 놓친 근거를 복구하는 경로입니다. 가려진 정점을 이웃 관측으로 대신 채우거나 실제 누락된 프레임을 보간해 통과시키지 않습니다. `contact_observed`, 직접 대상 식별 여부와 직접 판정 기준은 변경하지 않았습니다. 영상 추정은 물리 접촉을 직접 관측한 판정이나 측정된 정확도가 아닙니다.

## 재현과 검증

기준 원본은 저장소의 `8k 30 4k 24 a시점 1.mp4`와 `b시점 1.mp4`입니다. A SHA256은 `0cc88d220b046572383d67714b608881da45e15e5165b421d46b5b31667727bb`, B는 `bcac92b83d0e03f45acb66fdcf3fe6535acbef0aed53449ed96cfdf5aeb090e9`입니다. 현재 사용자 PC 파일과의 바이트 동일성은 별도 확인하지 않았습니다.

0.5.13 새 분석은 A 복식 영상 추정 IN과 직접 진단 REVIEW가 함께 나왔고, B는 독립 판정 REVIEW였습니다. 수정본은 이 원본을 처음부터 분석해 복식 최종 IN·단식 최종 OUT, A의 실제 추정 네 단계 충족, B 보조 시점 구분, 원본 근거 표시·새로고침을 검사합니다. 기존 개발 영상 회귀 확인이며 새 영상에 대한 정확도 측정은 아닙니다.

원본 재확인 시험은 추적만 정점을 놓친 경우와 원본 정점이 한 프레임 또는 인접 두 프레임 가려진 경우를 구분합니다. 정지 장면·반등 없음·원본 시간 간격 누락·경계 교차도 확인하며, 근거가 없는 음성 사례는 REVIEW를 유지해야 합니다. 실제 영상 실행과 합성 픽셀·추적 누락 주입 시험은 별도로 기록합니다.

```bash
python -m pytest -q
node tests/test_pair_region_ui.cjs
```

Windows 작업은 기본판 9개 payload 구조를 사용합니다. 최종 ZIP을 한글·공백 경로에 풀어 PowerShell 5.1 시작·재실행·HTTP 응답과 번들 Python의 실제 A/B 복식·단식 분석을 검사합니다. 성공한 파일은 `badminton-windows-0.5.14` Actions 아티팩트에 ZIP·SHA256·실행기 보고서·영상 분석 보고서로 저장합니다. PyTorch 포함판은 생성하지 않습니다.
