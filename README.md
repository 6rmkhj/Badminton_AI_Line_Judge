# 배드민턴 AI — Windows 실행 패키지

이 브랜치는 Windows 10/11 64비트 실행 패키지를 전달하기 위한 배포용입니다.

1. 이 브랜치를 **Code → Download ZIP**으로 다운로드합니다.
2. ZIP을 쓰기 가능한 폴더에 전부 압축 해제합니다.
3. 맨 위의 **START.bat**을 더블클릭합니다.
4. 첫 실행에서 포함 파일의 압축을 풀고 브라우저를 엽니다. A/B 영상을 업로드해 분석합니다.

Python, NumPy, SciPy, OpenCV, filelock, FFmpeg/ffprobe가 포함됩니다.
별도 Python 설치나 실행 중 인터넷 다운로드는 필요하지 않습니다.
다운로드 약 230MiB, 첫 실행 압축 해제 후 약 900MiB의 저장 공간을 사용합니다.

원본 경기 영상·과거 분석 결과·학습된 PyTorch 모델은 포함하지 않았습니다.
기본 OpenCV 분석이며, 판정 근거가 부족하면 REVIEW를 표시합니다.

앱 소스 기준: `d4911245a41ff80c794252d5f3dfa1fd6bb74fa6` (0.5.1).
앱 전체 테스트 420개와 Linux Chromium의 실제 업로드·분석·진행 기록·복원 및 PC/모바일 표시 검증을 통과했습니다.
Windows 실행 파일 자체는 Linux 환경에서 실행 검증하지 못했습니다.
상세 사용법·라이선스·검증 범위는 첫 실행 후 생성되는 사용방법.txt, licenses/, PACKAGE_VALIDATION.txt에 있습니다.

GitHub의 단일 파일 크기 제한을 지키기 위해 payload/에 구성 요소별 ZIP으로 보관합니다.
START.bat이 이 파일들을 자동으로 압축 해제합니다. payload/ 파일을 따로 열 필요는 없습니다.
