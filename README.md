# AI 검수 참고 영상: IN / OUT

**현재 0.5.7 기본 자동 분석으로 IN/OUT을 확정하는 예제가 아닙니다.** 각 B 영상을 배포 앱의 코드·설정으로 다시 전체 분석했고 둘 다 `REVIEW`였습니다. 자동 결과와 이유는 `AUTOMATIC_RESULTS.json`에 있습니다. AI 검수 레이블을 자동 추론에 입력하지 않았습니다.

| 폴더 | A에 선택할 파일 | B에 선택할 파일 | B 시점의 AI 검수 참고 접촉 구간 |
|---|---|---|---|
| IN | 8k 30 4k 24 a시점 4.mp4 | 8k 30 4k 24 b시점 4.mp4 | 약 2.46초, f58–60, 가까운 반코트 내부 |
| OUT | a시점 7.mp4 | b시점 7.mp4 | 약 1.90초, f113–115, 가까운 복식 사이드라인 바깥 |

ZIP 전체를 압축 해제하고 같은 폴더의 A/B 두 파일을 한 쌍으로 선택하세요. IN의 A와 OUT의 B를 섞으면 다른 경기입니다. 원본 영상 파일은 변환하거나 판정 자막을 삽입하지 않았습니다. 원본 해시와 파일 목록은 `MANIFEST.json`에 있습니다.

두 A 영상의 직접 접촉 레이블은 UNKNOWN입니다. 원본의 두 동작을 대조한 AI 검수로 B와 같은 사건이라고 연결했으며 정확한 시계 동기화를 주장하지 않습니다. IN/OUT은 해당 B의 최초 접촉 구간과 복식 외곽선을 AI가 시각 검수한 참고 결과입니다. 독립 사람이 확인한 정답이나 자동 판정 정확도가 아닙니다. OUT의 정확한 단일 접촉 프레임은 확정하지 않았고 프레임 사이 구간으로 기록했습니다.

당시 검수 JSON의 출처·레이블은 바꾸지 않고 함께 넣었습니다. JSON에 기록된 과거 runs/ 근거 경로 일부는 이 ZIP에 없습니다. 이번에 원본에서 다시 확인한 접촉 연속 이미지와 두 시점 동작 대응 이미지는 `evidence/`에 있습니다.

현재 자동 판정은 접촉 관측·대상 셔틀 식별·코트 보정 근거가 부족합니다. 이 영상에 IN/OUT이 나온다고 안내할 수 없으며, 셔틀 후보를 찾는 것과 자동 라인 판정은 구분해야 합니다.
