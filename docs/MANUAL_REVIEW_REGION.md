# 선택적인 검토 영역 지정

A/B 입력 화면에서 각 시점의 **검토 영역 지정**을 펼치면 원하는 코트와 셔틀콕의 이동 구간을 사각형으로 지정할 수 있습니다. 지정하지 않으면 기존 자동 분석을 사용합니다.

1. 기존 영상을 선택하거나 새 영상을 올립니다. 미리보기의 재생 막대로 원하는 장면을 찾습니다.
2. **영상에서 영역 그리기**를 누르고 영상 위를 드래그합니다. 그리기가 끝나면 재생·탐색 조작을 다시 사용할 수 있습니다. 그리기 도중에는 Esc 또는 취소 버튼으로 돌아갑니다.
3. 키보드를 사용할 때는 왼쪽·위쪽·너비·높이 비율을 입력합니다. 비율은 검은 여백을 제외한 영상 전체를 기준으로 합니다.
4. **지정 영역으로 A/B 분석**을 누릅니다. 한 시점에만 지정해도 됩니다. **지정 해제**하면 해당 시점은 자동 탐색으로 돌아갑니다.

영역은 수동 탐색 보조입니다. 셔틀콕의 정체, 실제 접촉, 코트 경계 또는 IN/OUT을 확정하지 않습니다. 선택한 프레임은 영역을 그리기 위한 장면이며, 영역은 영상 전체 시간에 적용됩니다. 셔틀콕이 지나가는 구간을 함께 포함하세요.

영상을 바꾸면 해당 시점의 영역은 초기화됩니다. 화면 크기가 바뀌어도 비율은 유지되며, 저장된 작업을 다시 열면 입력 영상과 영역을 복원합니다. 완료된 작업의 **검토 영역 지정 후 다시 분석**을 사용하면 저장된 업로드 원본을 다시 전송하지 않고 새 분석을 시작할 수 있습니다. 원본 코덱을 브라우저가 재생하지 못하면 먼저 분석한 뒤 변환된 미리보기에서 지정할 수 있습니다.

영역을 지정하면 기존 검수 재사용은 꺼집니다. 결과에는 `user_region_reanalysis`와 `operator_region_guided_search` 출처가 표시되며, 독립적인 자동 정확도 평가 대상으로 취급하지 않습니다. 영역만으로 실험용 관측 복구 기능이 켜지지는 않습니다.

API는 각 입력에 선택적으로 다음 필드를 받습니다. 생략하거나 `null`이면 영역이 없습니다. 숫자는 모두 유한해야 하며, 사각형은 `[0, 1]` 범위 안에 있어야 합니다.

```json
{"views":{"A":{"video_id":"v_a","review_region":{"x":0.1,"y":0.2,"width":0.6,"height":0.5}},"B":{"upload_id":"saved-upload"}},"reuse_review":false}
```

브라우저 개발 검증은 Playwright와 Chromium이 설치된 환경에서 `node tests/test_pair_region_ui.cjs`로 실행합니다. 이 검증은 합성 영상과 API 응답 모형을 사용하며 실제 분석을 시작하지 않습니다. 실제 영상의 추적·착지 성능 검증과는 별개입니다.
