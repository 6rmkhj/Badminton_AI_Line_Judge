# 배드민턴 AI — Windows 실행 패키지 0.5.2

1. 이 브랜치의 **Code → Download ZIP**으로 다운로드합니다.
2. **새 폴더에 전부 압축 해제**합니다.
3. 맨 위의 **START.bat**을 더블클릭합니다.
4. 브라우저에서 A/B 영상을 올리고 새 분석을 실행합니다.

Python, NumPy, SciPy, OpenCV, filelock, FFmpeg/ffprobe가 포함됩니다. 별도 설치나 실행 중 다운로드가 필요하지 않습니다. 다운로드 약 230MiB, 첫 실행 후 약 900MiB 공간이 필요합니다.

이번 버전은 셔틀콕 탐지·연속 궤적·첫 반등 추정과 확대 근거를 개선했습니다. 진행 단계와 경과 시간도 표시합니다. 추정 위치는 확정 판정이 아니며 근거가 부족하면 REVIEW를 유지합니다.

앱 소스 기준: `7e74b058ae95543bb9c7d121761426462e74f49c` (0.5.2). 전체 테스트 468개와 Linux Chromium의 실제 A/B 업로드·재분석·PC/모바일 검증을 통과했습니다. 두 입력 영상은 개발에 사용했으므로 독립 정확도 평가가 아닙니다. Windows 실행 파일 자체는 Linux에서 직접 실행 검증하지 못했습니다.

상세 결과: 첫 실행 후 `app/docs/SHUTTLE_TRACKING_FIX.md`. 사용법·라이선스·검증 범위는 `사용방법.txt`, `licenses/`, `PACKAGE_VALIDATION.txt`에서 확인하세요. 원본 경기 영상·과거 분석 결과·학습된 모델은 포함하지 않습니다.

`payload/`의 ZIP들은 GitHub 파일 크기 제한을 맞춘 구성 요소입니다. START.bat이 자동으로 압축을 해제하므로 따로 열지 않아도 됩니다.
