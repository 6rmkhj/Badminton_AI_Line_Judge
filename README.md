# 배드민턴 AI — Windows 실행 패키지 0.5.3

1. 이 브랜치의 **Code → Download ZIP**으로 다운로드합니다.
2. **새 폴더에 전부 압축 해제**합니다.
3. 맨 위의 **START.bat**을 더블클릭합니다.
4. 브라우저에서 A/B 영상을 올리고 새 분석을 실행합니다.

Python, NumPy, SciPy, OpenCV, filelock, FFmpeg/ffprobe가 포함됩니다. 별도 설치나 실행 중 다운로드가 필요하지 않습니다. 다운로드 약 241MiB, 첫 실행 후 약 900MiB 공간이 필요합니다.

이번 버전은 희미한 후보의 원본 재탐색, 궤적 연결, 외형 변화와 반동 근거 검사를 보완했습니다. 진행 단계와 경과 시간도 표시합니다. 추정 위치는 확정 판정이 아니며 근거가 부족하면 REVIEW를 유지합니다. 다중 코트와 가림 등 남아 있는 실패 사례를 포함한 실제 검증 결과는 `app/docs/GENERALIZATION_VALIDATION.md`를 확인하세요.

앱 소스 기준: `868b1e38700ad3613f83835b71857ae36d898814` (0.5.3). 전체 Python 테스트 556개를 Linux에서 통과했습니다. AI 시각 참조와의 비교는 독립 사람이 확인한 정확도 평가가 아닙니다. Windows 실행 파일 자체는 Linux에서 직접 실행 검증하지 못했습니다.

사용법·라이선스·검증 범위는 `사용방법.txt`, `licenses/`, `PACKAGE_VALIDATION.txt`에서 확인하세요. 원본 경기 동영상·대용량 분석 실행 폴더·학습된 모델은 포함하지 않습니다. 검증 문서, 일부 근거 이미지와 AI 참고 주석은 포함합니다.

`payload/`의 ZIP들은 GitHub 파일 크기 제한을 맞춘 구성 요소입니다. START.bat이 자동으로 압축을 해제하므로 따로 열지 않아도 됩니다.
